# Méthodes de documentation

## Règles

- Ne créer de fichiers `.md` que si la demande l'exige explicitement.
- Respecter le style et la langue des documents existants (structure, ton, nommage).
- Résumer plutôt que copier : pas de contenu dupliqué inutilement.
- Pas d'emojis sauf demande explicite.
- Ne jamais commiter, sauvegarder ou dévoiler des secrets/clés.

## Déroulé

- Identifier les documents existants (README, docs, changelog) avant d'écrire.
- Mettre à jour les fichiers concernés en un seul passage.
- Vérifier la cohérence avec le code réellement présent.

## Rapport

- Fichiers créés/modifiés.
- Résumé court des changements.
- Points d'attention éventuels.
